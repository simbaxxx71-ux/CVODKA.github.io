Вход в пространство

Владелец — полный доступ. Наблюдатель — только просмотр.

Новое пространство

Сначала настройте Firebase (вкладка «Firebase»). Запомните оба кода — восстановить их нельзя.

Подключение Firebase

Вставьте весь текст firebaseConfig в поле ниже — поля заполнятся сами. Либо введите вручную.

Где взять значения
1. console.firebase.google.com → проект
2. Build → Realtime Database → Create → test mode
3. Вкладка Rules → вставьте правила ниже → Publish
{"rules":{".read":true,".write":true}}
4. ⚙️ Project settings → Your apps → Web → Register
5. Скопируйте показанный код → вставьте в верхнее поле → «Распознать»
6. Если databaseURL пустой — скопируйте URL из страницы Realtime Database
